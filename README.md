# **🚩 Week 3 – Password Cracking & Security Auditing**

## **📌 Project Overview**

This repository contains my Week 3 practical projects completed as part of the **Cybersecurity & Ethical Hacking Training Program** organized by **NETWORKWALKS**.

The main objective of this week's tasks was to understand password security, password hashing, authentication mechanisms, and password auditing techniques using different cybersecurity tools in Kali Linux.

## **🎯 Project Modules**

### **🔐 W3-PM1: Password Cracking Using John the Ripper & Johnny GUI**

**Tools Used:**

- John the Ripper (JTR)
- Johnny GUI
- Kali Linux

**Tasks Performed:**

- Understanding password hashes.
- Identifying password hash formats.
- Performing dictionary-based password auditing.
- Using John the Ripper for password recovery.
- Exploring password cracking through Johnny GUI.
- Verifying the results of password auditing.

### **🔐 W3-PM2: Password Cracking Using NetworkWalks Tools**

**Tools Used:**

- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker

**Tasks Performed:**

- Understanding hash generation and verification.
- Exploring different password hashing techniques.
- Using the Hash Calculator tool.
- Performing password recovery using the Password Cracker.
- Understanding password vulnerabilities.
- Successfully capturing the project flag.

## **📚 Key Learnings**

- Understanding password hashing and authentication.
- Learning dictionary-based password attacks.
- Exploring password auditing techniques.
- Understanding weak password vulnerabilities.
- Learning the importance of strong and unique passwords.
- Understanding Multi-Factor Authentication (MFA).
- Gaining practical experience with cybersecurity tools.
